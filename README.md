# Hi, I'm Eko Sarwono 👋

**Mechanical Engineer → AI Automation Engineer**

I spent 15+ years in EPC (Engineering, Procurement & Construction) projects for power plants and industrial facilities. Now I build practical **workflow automations and AI agents** that take repetitive work off people's plates, with the same engineering mindset: clear requirements, reliable systems, and documentation others can follow.

## What I build

- **AI agents** with tool calling, memory and model fallback
- **RAG chatbots** that answer only from a company's own documents
- **Workflow automations** connecting Telegram, Google Workspace, databases and REST APIs
- **Document automation**: turning chat or data into styled Word and PDF files
